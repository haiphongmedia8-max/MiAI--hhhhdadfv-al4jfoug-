## Tính năng

### Ứng dụng chào hỏi (Greeting Application)

Ứng dụng đơn giản để chào hỏi người dùng bằng tiếng Việt.

#### Cách sử dụng

1. Chạy ứng dụng:
```bash
python3 greet.py
```

2. Nhập tên của bạn khi được yêu cầu, hoặc nhấn Enter để bỏ qua.

#### Chạy kiểm thử

Để chạy các bài kiểm thử tự động:
```bash
python3 test_greet.py
```

## Yêu cầu

- Python 3.x

## Mô tả

Ứng dụng này cung cấp chức năng chào hỏi cơ bản:
- Chào người dùng bằng tiếng Việt
- Có thể cá nhân hóa lời chào với tên người dùng
- Bao gồm các bài kiểm thử đơn vị
